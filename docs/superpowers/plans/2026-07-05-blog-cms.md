# Blog + Full-Site CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a blog and a Payload CMS 3 admin at `/admin` that manages all site content (posts, projects, media, homepage, settings), after upgrading the site from Next.js 12 / React 17 pages-router to Next.js 15 / React 19 App Router and moving hosting from Netlify to Vercel.

**Architecture:** One Next.js 15 App Router app. Route group `app/(site)` holds the public portfolio + blog; route group `app/(payload)` holds the Payload-generated admin. Data in Neon Postgres via `@payloadcms/db-postgres`; media uploads in Vercel Blob. Public pages read through the Payload Local API in server components, static-first with ISR + `revalidatePath` hooks on publish.

**Tech Stack:** Next.js 15, React 19, Payload CMS 3 (latest 3.x), `@payloadcms/db-postgres` (Neon), `@payloadcms/storage-vercel-blob`, `@payloadcms/richtext-lexical`, Tailwind 3 (existing), `motion` (framer-motion replacement), Playwright for smoke tests.

**Spec:** `docs/superpowers/specs/2026-07-05-blog-cms-design.md`

## Global Constraints

- Branch: all work on `feat/cms-blog`, branched from `main`.
- Parity gate: after Task 5 the public site must look and behave identically to production (fonts, copy, dark mode, animations) before any CMS code lands.
- WCAG AA (from PRODUCT.md): alt text required on all media, `prefers-reduced-motion` respected (existing components already do this — do not remove `useReducedMotion` calls).
- Env var names, exact: `DATABASE_URL`, `PAYLOAD_SECRET`, `BLOB_READ_WRITE_TOKEN`, `NEXT_PUBLIC_GA_ID`.
- Site URL: `https://amirseraj.ir`. Contact email: `amirseraj.ir@gmail.com`.
- Blog scope is CORE ONLY (spec): no search, RSS, comments, scheduling, newsletter. Do not add them.
- Existing tsconfig path aliases: `@components/*`, `@styles/*`, `@utils/*`. New alias added in Task 7: `@payload-config`.
- Node local: v25. Vercel: Node 24 default. Both fine for Next 15.
- Project `body` fields are **raw HTML strings with Tailwind classes** (current DataProjects.js format). They stay HTML (textarea field), NOT Lexical. Only blog posts use Lexical.
- Every task ends with `npm run build` passing and a commit.

## Known Deviations from Spec (approved rationale)

1. **Cypress dropped, Playwright added.** `cypress/integration` contains only the Cypress 9 kitchen-sink examples — zero real tests — and Cypress 9 does not run on Node 25. Playwright provides the spec's smoke tests.
2. **Existing project images stay in `/public/images`.** Project `coverImage`/`socialImage` and `<img>` tags inside body HTML keep their static paths (parity + 13 projects × dozens of images not worth migrating). Vercel Blob is used for NEW uploads (blog covers, media collection).
3. **Tailwind classes inside DB-stored project body HTML** can no longer be discovered by Tailwind's content scan once `DataProjects.js` is deleted. Fix: a `prebuild` script extracts all `class="..."` tokens from the DB into `lib/body-classes.txt`, which is listed in `tailwind.config.js` `content`. (This is the same class of bug as commit bd9d6d0 "fix site-wide Tailwind content bug" — do not skip.)

export async function getProject(slug: string): Promise<Project | null> {

export async function getPublishedPosts(tagSlug?: string): Promise<Post[]> {
  const p = await payload();
  const where: any = { _status: { equals: "published" } };
  if (tagSlug) where["tags.slug"] = { equals: tagSlug };

}

import { getPost, getPublishedPosts, getSettings } from "../../../../cms/queries";

type Params = { slug: string };

export async function generateMetadata({ params }: { params: Promise<Params> }): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) return {};
  const settings = await getSettings();
  const url = `${settings.siteUrl}/blog/${slug}`;
  const og = typeof post.seo?.ogImage === "object" ? post.seo?.ogImage?.url : undefined;
  return {
    title: post.seo?.metaTitle || post.title,
    description: post.seo?.metaDescription || post.excerpt || undefined,
    alternates: { canonical: url },
    openGraph: { url, type: "article", images: og ? [og] : undefined },
  };
}

export default async function PostPage({ params }: { params: Promise<Params> }) {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) notFound();
  const cover = typeof post.coverImage === "object" ? post.coverImage : null;

  return (
    <main>
      <Nav className="fixed py-3 bg-white bg-opacity-75 backdrop-blur dark:bg-[#323232] dark:bg-opacity-90" />
      <PrismHighlight trigger={slug} />
      <Container className="pt-32 pb-20">
        <article className="prose prose-slate mx-auto dark:prose-invert lg:prose-lg">
          <h1 className="font-heading">{post.title}</h1>
          <p className="text-sm uppercase tracking-wider text-slate-500 dark:text-slate-400">
            {post.publishedAt && new Date(post.publishedAt).toLocaleDateString("en-GB", { year: "numeric", month: "long", day: "numeric" })}

          </p>
          {cover?.url && (
            <Image src={cover.url} alt={cover.alt ?? post.title} width={1280} height={720} priority className="w-full" />
          )}
          <RichText data={post.body} />
        </article>
      </Container>
    </main>
  );
}
